# Seedance 2.0 提示词指南（要点摘编）

Seedance 2.0 没有像 MiniMax H3 那样独立的官方 markdown 提示词文档；字节官方主要给产品介绍与参数，最具体的提示词写法来自 Runway 平台的创作指南（Seedance 2.0 在其平台以第三方模型提供）。本文件据此整理，并保留对官方资料的引用。

- Runway 创作指南（最具体的提示词写法）：https://help.runwayml.com/hc/en-us/articles/50488490233363-Creating-with-Seedance-2.0
- 字节官方介绍：https://seed.bytedance.com/en/seedance2_0

> 注意：下面带「Runway 平台」字样的参数（如时长 5–15 秒、分辨率 480p/720p/1080p、提示词上限 10000 字符、文件大小与类型）是 Runway 这一接入方的限制，不等于模型本身或秘塔接口的通用限制。秘塔接口当前允许 Seedance 4–15 秒、分辨率见 [SKILL.md](SKILL.md)；以秘塔实时校验为准。

## 1. 三种创建模式

Seedance 2.0 提供三种模式，按需求选择：

- **References（参考）**：最适合把多张图片或视频的元素融合进同一次生成，对每份输入取什么做精细控制。
- **Start / End frames（首尾帧）**：最适合传统图生视频（仅首帧）或关键帧控制（首尾帧），需要精确控制镜头如何开始或结束。
- **Text to video（文生视频）**：最适合不带任何图/视频输入直接生成；处理写实人物时也好用，因为能避开图像输入带来的一些审核约束。

## 2. 通用提示词原则

无论哪种模式，都用**正向、无歧义、结果导向**的语言描述你想要的画面，而不是写"不要怎样"。Seedance 是统一多模态架构，你设定每个输入的角色，模型据此生成带同步声音的视频。

## 3. 使用参考输入

参考模式里，把提示词写成在描述你希望出现的场景/镜头或想要做的改动，并说明**每份输入各自的用途**。参考输入本就灵活：无论是图还是视频，逐一定义它们承担的角色。示例思路：

> 以图片 1 作为人物外观参考，以图片 2 提供雨夜街景；人物撑伞向街角缓步走去，镜头从侧面缓慢跟随。环境有细密雨声和远处汽车驶过的声音。

首尾帧模式要明确起点、终点以及两者之间的变化；不要把普通参考图默认当作首帧。

## 4. Runway 平台参数（仅供参考，非秘塔限制）

| 项目 | 取值 |
| --- | --- |
| 时长 | 5–15 秒（Runway 平台；秘塔为 4–15 秒） |
| 比例 | 21:9、16:9、4:3、1:1、3:4、9:16 |
| 输出分辨率 | 480p、720p、1080p |
| 最大提示词长度 | 10000 字符 |
| 支持输入 | 文本、图片、视频、音频 |
| 模式 | 文生视频、图生视频、视频生视频、音频生视频 |
| 最多输入 | 图片 9 / 视频 3（总时长 < 15 秒）/ 音频 3（总时长 < 15 秒） |
| 文件大小 | 参考图 < 30MB；参考视频 < 50MB |
| 文件类型 | 图 jpg/jpeg/png/webm；视频 mp4/mov；音频 mp3/wav/m4a |
| 尺寸要求 | 图 >300px 且 <6000px；视频 ≤ 720p |

秘塔接口实时配置（以 `/api/video-generation/models` 为准）列出最多 9 图、3 视频、3 音频、单视频 ≤ 52428800 字节；具体费用、组合与有效 URL 以秘塔当前页面为准。

## 5. 与 H3 的区别

Seedance 不需要 H3 的三段/六段英文结构、`<d>`/`<Subject N>` 标签。用自然语言写清期望出现的主体、环境、动作顺序、镜头变化和声音即可；参考素材逐个说明角色。H3 的字段结构是 H3 专属，见 [MiniMax H3 提示词指南](minimax-h3-prompts.md)。
