# Seedance 2.0 提示词指南（官方摘编 + 最佳实践）

主要依据火山方舟官方《Doubao Seedance 2.0 系列提示词指南》：
https://docs.volcengine.com/docs/ark/seedance-2-0-prompt-guide?lang=zh

该指南针对 Seedance 2.0 本身，即秘塔接口中的 `seedance-2.0` 与 `seedance-2.0-mini`。Runway 的创作指南
（https://help.runwayml.com/hc/en-us/articles/50488490233363-Creating-with-Seedance-2.0）提示词写法也可借鉴，但其中
的时长 / 分辨率 / 字数 / 文件限制是 Runway 接入方限制，不等于秘塔接口限制。

> 注意：下方带「秘塔」字样的内容才是 metaso.cn 接口的限制；以 [SKILL.md](SKILL.md) 与秘塔实时模型配置为准。
> Seedance 接口尚未以付费生成实测；遇到服务报错保留原始信息并核对当前文档，不猜测重试。

## 1. 模型能力概览

Seedance 2.0 原生支持音频与视频联合生成，拥有语义理解与全模态交互能力，可同时参考视频、图片、音频等素材，
精准锁定人物样貌、动作特效、视觉风格、配音音色等特征。模型像「导演」：内部把输入拆成 **空间层**（画面里有什么）
和 **时间层**（事情如何随时间变化）两个维度来理解和生成。

## 2. 基础公式（按参考任务类型选择）

参考生视频分三类，先选定任务再套公式：

| 任务 | 说明 | 适用 | 推荐句式（`<图片N>`/`<视频N>`/`<音频N>` 指你提供的第 N 份素材） |
| --- | --- | --- | --- |
| 全模态参考 | 从素材提取部分元素（主体 / 风格 / 场景 / 音效）生成全新视频 | 动作迁移、主体复用、氛围借鉴 | 图片：`参考 <图片N> 中的 <主体N>，生成…`；视频：`参考 <视频N> 中的 <运镜/风格/音效>，生成…`；音频：`参考 <音频N> 中的音色，生成…` |
| 编辑视频 | 在原视频上局部 / 全局修改，未提及部分默认保持不变 | 局部替换、主体抹除、属性修改 | `参考 <视频N> 中的…，编辑 / 替换成…`（点明要删除的元素，对保持不变的元素在提示词中强调） |
| 延长视频 | 时间维度延续原视频，音视频风格、主体、叙事保持一致 | 续写剧情、延展动作、补全片段 | 直接用「视频」指代原视频，**不要**用「参考」，以免被误判为参考任务 |

纯文生视频不要加任何参考素材，以免被误判为参考任务。

## 3. 进阶公式：工程型指令

好提示词不是「文案型形容」，而是「工程型指令」：谁、在什么场景、做什么动作、镜头如何运动、按怎样的时间顺序发生。

> 先锁定「谁」在「干什么」，再交代「在哪」「什么氛围」，然后告诉模型「怎么拍」，最后用风格、画质和约束条件把结果收紧。

## 4. 主体定义

一张参考图里往往有多个主体，必须明确指代，避免省略：

- **未定义主体的简单场景**：每次提到主体都用 标签 + 素材 绑定，例如 `张三<图片1>`。
- **已定义主体的场景**：先把每个主体定义成固定标签（如 `将高个子男人定义为 A<图片1>`、`将矮个子男人定义为 B<图片2>`），后续持续用同一标签指代。
- 模型无法直接把「名称」与参考内容关联，所以**不可只用名称指代**，必须带标签。
- 描述尽量简洁，避免冗余与语义冲突（同一主体出现矛盾特征）。
- 空间关系优先通过参考图表达，减少复杂文字描述。

## 5. 时间轴化分镜

模型内部空间与时间解耦，复杂视频最理想的形态是**时间轴化分镜**：把视频拆成若干镜头，按事件发生顺序动态描述
每个镜头（谁、在哪、做什么、镜头怎么动）。

- 用 `镜头1 / 镜头2 …` 标识，按事件顺序（先主后次）组织。
- 不强制限制每段时长，让模型按剧情自然生成节奏；**精确秒数（如「前 2 秒」）支持不稳定，强行限制可能导致异常**。
- 反例：「男人在街头紧张地奔跑，画面很有电影感。」
- 正例：
  - 镜头1：街巷侧拍，男人缓慢起跑，带有急促的呼吸感。
  - 镜头2：男人撞翻水果摊，镜头快速摇动并给到男人惊恐的特写。
  - 镜头3：男人翻过矮墙消失，镜头缓慢拉远定格在空荡的街道。

每个镜头推荐按以下逻辑组织：

1. **运镜 / 切换方式**：如「全景缓慢推近」「固定机位」「镜头切至 <主体>」。模型对运镜词理解力强，直接用语：
   中景、特写、全景、缓慢推镜、平稳横移、固定镜头。一个镜头尽量只指定 **1 种** 运镜方式，不要同时推拉摇移（增加不稳定性）。
2. **动作**：具体到手、腿、头部、肩背等肢体部位，并补充幅度 / 速度（缓慢抬手、快速转头、用力蹬地、微微低头）。
   优先缓慢、轻柔、连贯的细微动作，规避狂奔、大跳、剧烈翻滚等高爆发大动态；写明前后动作的惯性与承接
   （「借着转身惯性顺势抬手」）。用具体身体细节表现情绪，替代「很悲伤」「非常愤怒」等抽象词（见第 9 节情绪外化示例）。
3. **场景**：说明主体所处场景、位置或空间关系。
4. **声音**：对应镜头的音效、人声或背景音乐。

## 6. 画质 / 风格 / 约束词

- 画质：`高清，细节丰富，电影质感，色彩自然，光影柔和`
- 风格：`赛博朋克冷蓝紫色调`、`复古胶片`、`日系清新`、`国风漫画` 等，统一美术调性。
- 约束词（规避瑕疵 / 畸形 / 随机偏差，必要）：`保持无字幕`、`避免生成任何文字或字幕`、`不要生成水印`。

## 7. 文字与字幕生成

模型支持生成广告语、字幕、气泡等常用文字，能根据情境匹配风格与颜色，并支持指定文字的颜色、风格、出现方式、时机、位置。
编写时优先使用官方推荐的明确写法，确保最佳呈现（具体写法与案例以官方指南为准）。

## 8. 素材的功能角色与数量

通常把素材分成四种功能角色：

1. **场景定调**：锁定环境与风格
2. **角色锚定**：锁定角色外观
3. **运镜参考**：锁定镜头语言与动作节奏
4. **节奏氛围**：用音频控制情绪、音色

- **不建议用满素材上限**：过多素材会让模型难以判断特征优先级，易出现风格冲突、主体识别模糊、生成偏离预期。
- 台词语言统一，避免中英文混用（专有名词除外）。
- 提示词中合理使用符号（如方括号、引号）有助于模型区分不同信息类型。

## 9. 常见问题与对策

| 问题 | 对策 |
| --- | --- |
| 人脸参考不准确 / 中途「换脸」/ 撞脸明星 | 把人脸参考图与全身 / 半身姿态图、服装参考图、细节图合并进同一张图；额外准备一张 **大头照**（仅保留面部、无表情最佳，减少肩颈背景干扰）作为人脸特写；**不要用三视图 / 多视图作人脸参考**（会被识别成多个主体）。人物参考优先用单人独立照片。 |
| 未要求字幕却生成字幕 | 加约束「保持无字幕」「避免生成任何文字或字幕」；非必要文字先去除（用视频编辑能力去文字）再作输入；优先 **横屏** 生成（字幕概率低于竖屏），后期裁剪成竖屏。 |
| 出现其他平台水印 | 加约束「不要生成水印」「不要生成 XX 平台水印」。 |
| 风格漂移（如要动漫却偏写实） | 加明确风格约束词（如「赛博朋克」「国风漫画」）；精准控制可先把参考图转成目标风格再生视频。 |
| 视频延长拼接处跳变 / 回退 | 延长时以「转场切镜」时刻结尾、下一段以切镜后新场景为起始；衔接处用剪辑软件对齐关键帧修补。 |
| 同一画面出现两个相同人物（双胞胎） | 清晰定义每个人物并在名称后标注对应参考图、格式统一；提示词末尾加固定约束：`视频全程禁止出现外形、着装、配饰完全一致的人物，禁止生成同款分身、双胞胎效果，同一画面中仅保留单个对应人物，不出现人物重复复刻`。人物参考图优先单人独立照片，不建议三视图 / 多视图。 |
| 把整篇剧本直接当提示词 | 精简无关表述、保证指令清晰聚焦，勿直接粘贴完整剧本。 |
| 续写后画质劣化（人脸斑驳色块） | 转白模再续写：`将视频转为白色模型，人物统一为纯白模型，无色彩、无纹理、无阴影，纯白背景，结构稳定、运动流畅`；优先高清参考图；合理控制续写次数。 |
| 文字 / 数字特效不符（如倒计时乱跳） | 把目标特效视频作为参考素材输入，让模型理解特效形态与运动逻辑。 |
| 参考人物过多导致不稳定 | 分组生成（每组不超过上限人数）→ 用分组图片作参考再生成最终视频。 |
| 片尾「咔哒」杂音 | 剪辑软件对片尾音轨做音频淡出（关键点下拉音量到 0）。 |
| 多音字 / 生僻字读错 | 用同音字替换（如「螭龙山」→「吃龙山」）；小语种需标注语种（「用日语说道」）。 |
| 参考音频音色偏差 | 提示词补充细致音色特征（如「低厚温润带细碎颗粒感中年男声的音色说」）；台词风格与参考音频语气、表述相近。 |

## 10. 一镜到底 vs 分镜

- **一镜到底**：适用单一场景内的「文戏」（长对话、情绪递进、单一路径移动），沉浸连贯。
- **分镜**：适用剧情转折或复杂快速「武戏」（追逐、打斗、蒙太奇），可独立生成片段再剪辑组合，保证节奏与冲击。
- 实际常结合：先用延长生成连贯对话，再拼接空镜 / 转场。

## 11. 附录：提示词案例（精简）

- **主体多视角图参考**：模型支持主体多视角，也支持场景图、分镜图等多图；对图片顺序有要求时应标注顺序，指代清楚参考对象。
- **视频参考**：指代清楚生成内容与参考对象；对顺序有要求应标注。
- **多素材统一绑定**：多个素材指向同一主体时，统一用同一标签绑定。
- **台词写法**：说话角色周边出现气泡 / 画面底部字幕，内容与音频节奏同步；画外音示例「一个深沉、平静的男声说：…」。
- **静态特征锚定**：用 3 个清晰稳定的静态特征（服饰、发型、外观、类别）确保唯一可识别，例如把「红色连衣裙、戴草帽的女人」定义为某标签。
- **情绪外化（替代抽象词）**：
  - 喜悦：`嘴角抑制不住地上扬、眉眼舒展、脚步变得轻快、下意识地哼起小曲、忍不住原地转个圈`
  - 难过：`低头、肩膀微微颤抖、眼眶泛红、手指无意识地攥紧衣角、泪水在眼眶里打转但没有落下`
  - 放松：`长长地舒了一口气、紧绷的肩膀完全放松下来、脸上露出久违的淡淡微笑、抬头望向远方`
  - 愤怒：`双拳紧握、下颌线紧绷、胸口剧烈起伏、眼神如刀般锐利、从牙缝里挤出话语`
  - 紧张：`频繁地看手表、手指不停敲击桌面、呼吸急促、眼神闪躲、无意识地啃咬指甲`

## 12. 与 H3 的区别

Seedance **不需要** H3 的三段 / 六段英文结构、`<d>`/`<Subject N>` 标签。用自然语言写清期望出现的主体、环境、动作顺序、
镜头变化和声音即可，参考素材逐个说明角色。H3 的字段结构是 H3 专属，见 [MiniMax H3 提示词指南](minimax-h3-prompts.md)。
注意本文件的 `<图片N>`/`<视频N>`/`<音频N>` 只是提示词里指代素材的占位写法，与 H3 的标签语法无关。

## 13. 秘塔接口注意

- 素材通过 metaso 请求的 `content[]` 按 `role`（image / video / audio）与 `url` 提供；提示词文本里的 `<图片N>`/`<视频N>`/`<音频N>`
  对应你按顺序提供的第 N 份同类素材。具体 `content` 类型、素材数量与有效 URL 以 [SKILL.md](SKILL.md) 及秘塔实时模型配置为准。
- 秘塔模型配置列出最多 9 图 / 3 视频 / 3 音频；素材费用与组合限制以秘塔当前页面为准。
- 普通参考图不能当作首帧。
