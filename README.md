# METASO H3 视频生成技能

使用自己的秘塔 METASO API 余额，通过支持技能的 AI 助手生成 MiniMax H3 视频、查询任务并下载结果。脚本默认预览请求，只有明确提交才创建付费任务。

## 安装

[下载技能 ZIP](packages/metaso-h3.zip)，解压后将 `metaso-h3` 文件夹放入 AI 助手的技能目录。也可以让支持 GitHub 安装技能的助手安装本仓库中的 `metaso-h3` 目录。

需要 Python 3、自己的 METASO API Key 和可用的 METASO 余额。凭据配置与调用方法见[技能说明](metaso-h3/SKILL.md)，请勿将密钥提交到仓库。

## 使用

在支持技能的助手中说：

> 使用 $metaso-h3，帮我准备一段 4 秒、768P 的视频请求，先预览参数。

确认模型、素材、时长、分辨率、数量与费用后，再按需要提交。生成费用以秘塔当前页面及账户实际扣费为准。

当前脚本只支持 `MiniMax-H3`。秘塔页面也列出 Seedance 2.0 Mini 和标准版，但本技能尚未接入或验证这两个模型。

脚本支持提供符合 API 文档的素材 URL，但不提供独立文件上传。详细参数、任务查询和下载命令见[技能说明](metaso-h3/SKILL.md)。
